# 开发环境搭建

## 1. 文件传输 FTP 服务

```bash
# 安装
sudo apt install vsftpd

# 配置
sudo vim /etc/vsftpd.conf
```

| 关键配置 | 值 | 作用 |
|----------|-----|------|
| `anonymous_enable` | NO | 禁止匿名登录 |
| `local_enable` | YES | 允许本地用户登录 |
| `write_enable` | YES | 允许上传 |
| `local_root` | /home/alice/ftp | 锁定 FTP 根目录 |

```bash
sudo systemctl start vsftpd     # 启动
sudo systemctl enable vsftpd    # 开机自启
```

客户端连接：浏览器 `ftp://开发板IP` 或 FileZilla。

## 2. 开启 NFS 服务

NFS 让开发板通过网络挂载 Ubuntu 目录，方便共享文件。

```bash
# 安装
sudo apt install nfs-kernel-server

# 创建共享目录
mkdir ~/nfs_share

# 配置
sudo vim /etc/exports
```

| 配置 | 含义 |
|------|------|
| `/home/alice/nfs_share *(rw,sync,no_root_squash)` | 允许所有 IP 读写 |

| 选项 | 含义 |
|------|------|
| `rw` | 读写 |
| `sync` | 同步写入 |
| `no_root_squash` | 客户端 root 有完整权限 |

```bash
sudo exportfs -ra               # 使配置生效
sudo systemctl restart nfs-kernel-server
```

开发板挂载：

```bash
mount -t nfs -o nolock 192.168.1.100:/home/alice/nfs_share /mnt
```

## 3. 开启 SSH 服务

```bash
# 安装
sudo apt install openssh-server

sudo systemctl start ssh
sudo systemctl enable ssh
```

开发板连接：

```bash
ssh root@192.168.1.101
```

| 工具 | 用途 |
|------|------|
| `ssh` | 远程登录 |
| `scp` | 文件传输（ssh 协议） |

```bash
scp test.c root@192.168.1.101:/home/root/
```

## 4. 交叉编译器安装

交叉编译：在 x86 Ubuntu 上编译 ARM 程序。

| 概念 | 说明 |
|------|------|
| 本地编译 | 在 x86 编译 → x86 运行 |
| 交叉编译 | 在 x86 编译 → ARM 开发板运行 |

### 安装（以 arm-linux-gnueabihf 为例）

```bash
# 下载（Linaro 官方）
wget https://releases.linaro.org/components/toolchain/binaries/\
7.5-2019.12/arm-linux-gnueabihf/gcc-linaro-7.5.0-2019.12-x86_64_\
arm-linux-gnueabihf.tar.xz

# 解压
sudo tar -xvf gcc-linaro-*.tar.xz -C /usr/local/

# 添加到 PATH
vim ~/.bashrc
export PATH=$PATH:/usr/local/gcc-linaro-*/bin

source ~/.bashrc
```

### 验证

```bash
arm-linux-gnueabihf-gcc --version
```

### 使用

```bash
arm-linux-gnueabihf-gcc -o hello hello.c
# 生成的 hello 在 x86 上不能运行，需传到开发板执行
```

| 常用交叉编译器前缀 | 适用架构 |
|-------------------|----------|
| `arm-linux-gnueabihf-` | ARM Cortex-A，带硬浮点 (hf) |
| `arm-none-eabi-` | ARM Cortex-M 裸机 |
| `aarch64-linux-gnu-` | ARM 64 位 |

## 服务速查

| 服务 | 安装包 | 端口 | 作用 |
|------|--------|------|------|
| FTP | `vsftpd` | 21 | 文件传输 |
| NFS | `nfs-kernel-server` | 2049 | 目录共享 |
| SSH | `openssh-server` | 22 | 远程登录+传文件 |

> 三套服务搭建完成后，开发流程：交叉编译 → scp/NFS 传到开发板 → ssh 登录运行。
