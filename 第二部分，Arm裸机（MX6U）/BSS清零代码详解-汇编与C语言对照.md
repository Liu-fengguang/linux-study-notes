# BSS 清零代码详解：汇编与 C 语言对照

> 汇编没有隐藏逻辑，看到什么 CPU 就做什么。把它翻译成 C 语言就懂了。

---

## 一、这段代码在干什么

把内存中属于 BSS 段的区域全部填 0。C 语言标准规定未初始化的全局变量默认值必须为 0。

---

## 二、对应的 C 语言

```c
unsigned int *r0 = _bss_start;   // 指针指向 BSS 开头
unsigned int *r1 = _bss_end;     // 指针指向 BSS 末尾
unsigned int r2 = 0;             // 用来清零的值

while (r0 <= r1) {
    *r0 = r2;   // 当前位置填 0
    r0++;       // 指针 +1（实际地址 +4，因为 32 位/4 字节）
}
```

---

## 三、逐行拆解

### 初始化

```asm
ldr r0, _bss_start      @ r0 = BSS 起始地址（扫地起点）
ldr r1, _bss_end        @ r1 = BSS 结束地址（扫地终点）
mov r2, #0              @ r2 = 0（橡皮擦）
```

| 寄存器 | 相当于 C 变量 | 值 |
|--------|-------------|-----|
| `r0` | `unsigned int *p` | BSS 起始地址 |
| `r1` | `unsigned int *end` | BSS 结束地址 |
| `r2` | `unsigned int zero` | `0` |

### 循环体

```asm
bss_loop:               @ 循环入口标号，相当于 goto 锚点
    stmia r0!, {r2}     @ *r0 = r2;  r0++;  （两句合一）
    cmp r0, r1          @ 比较 r0 和 r1
    ble bss_loop        @ 如果 r0 <= r1，跳回 bss_loop
```

### stmia — 最核心的指令

```
stmia r0!, {r2}
││││  ││   │
││││  ││   └── 要存储的寄存器列表
││││  │└────── ! 表示写完后自动更新 r0（r0 = r0 + 4）
│││└──└─────── ia = Increment After（先存后加）
││└─────────── m = Multiple（可一次存多个寄存器）
│└──────────── t = Store（写内存）
└───────────── s = 指示这是一条存储指令的前缀
```

**一条指令干了两件事**：

| 操作 | 等价 C 语言 |
|------|------------|
| 把 r2 的值写入 r0 指向的地址 | `*r0 = r2;` |
| r0 自增到下一个 32 位字 | `r0++;`（实际 +4 字节） |

### cmp + ble — 循环控制

```asm
cmp r0, r1          @ 硬件做减法 r0 - r1，只影响标志位，不存结果
ble bss_loop        @ 如果 r0 <= r1（Less than or Equal），跳回
```

| 指令 | 含义 | 等价 C 语言 |
|------|------|------------|
| `cmp r0, r1` | 比较 | `if (r0 <= r1)` |
| `ble` | ≤ 时跳转 | `goto bss_loop;` |

---

## 四、寄存器 vs C 变量对照

| 汇编 | C 语言 | 说明 |
|------|--------|------|
| `r0, r1, r2...` | 局部变量 | 寄存器就是 CPU 内部的临时变量 |
| `ldr r0, _bss_start` | `r0 = *(_bss_start)` | 从内存加载 |
| `str r2, [r0]` | `*r0 = r2` | 写入内存 |
| `mov r2, #0` | `r2 = 0` | 赋值 |
| `stmia r0!, {r2}` | `*r0++ = r2` | 先存后自增 |

---

## 五、完整流程

```
准备工作
  r0 = BSS 起始地址
  r1 = BSS 结束地址
  r2 = 0
       │
  ┌─ bss_loop:
  │   把 0 写入 r0 指的地址  (stmia → *r0 = 0)
  │   r0 = r0 + 4            (自动自增)
  │   r0 <= r1 ?              (cmp + ble)
  │   是 → 跳回 bss_loop
  │   否 → 结束，执行下一句
  └──────────────────┘
       │
  ldr sp, =0x80200000     ← 清零完成，设栈指针
```

---

## 六、为什么非用汇编不可

| C 语言的问题 | 汇编的解法 |
|-------------|-----------|
| 变量本身要占栈 | 寄存器直接操作，不需要栈 |
| 指针变量放在哪里？此时栈还没设 | 寄存器 r0 本身就是指针 |
| 函数调用要栈帧 | 直接 `b` 跳转，不涉及栈 |

> BSS 清零发生在**栈还没设好之前**，不能用 C 函数，只能用寄存器硬扛。
