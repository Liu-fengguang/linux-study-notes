# 蜂鸣器实验

## 一、硬件原理

| 项目 | 说明 |
|------|------|
| 控制 IO | `SNVS_TAMPER1` |
| 复用为 | `GPIO5_IO01` |
| 高电平 | 蜂鸣器**关闭** |
| 低电平 | 蜂鸣器**打开** |

> 和 LED 逻辑一样：低电平导通，高电平截止。

---

## 二、寄存器地址

| 寄存器 | 地址 | 作用 |
|--------|------|------|
| `IOMUXC_SW_MUX_CTL_PAD_SNVS_TAMPER1` | `0x0229000C` | IO 复用 |
| `IOMUXC_SW_PAD_CTL_PAD_SNVS_TAMPER1` | `0x02290058` | 电气属性 |
| `GPIO5_GDIR` | `0x020AC004` | 方向（bit1 = 1 输出） |
| `GPIO5_DR` | `0x020AC000` | 数据（bit1 = 0 响，1 停） |

---

## 三、编程步骤

| 步骤 | 操作 | 关键代码 |
|------|------|----------|
| ① | 复用为 GPIO | `SW_MUX_CTL = 0x5`（ALT5） |
| ② | 设电气属性 | `SW_PAD_CTL = 0x10B0` |
| ③ | 设为输出 | `GPIO5_GDIR \|= (1 << 1)` |
| ④ | 输出电平控制 | `GPIO5_DR &= ~(1 << 1)` 响 / `\|=` 停 |

---

## 四、与 LED 实验对比

| | LED | BEEP |
|------|-----|------|
| GPIO | GPIO1_IO03 | GPIO5_IO01 |
| 复用寄存器 | `IOMUXC...GPIO1_IO03` | `IOMUXC...SNVS_TAMPER1` |
| 方向寄存器 | `GPIO1_GDIR` bit3 | `GPIO5_GDIR` bit1 |
| 数据寄存器 | `GPIO1_DR` bit3 | `GPIO5_DR` bit1 |
| 低电平 | 亮 | 响 |

> 换了一个 IO，套路完全一样：复用 → 电气 → 方向 → 数据。这是所有 GPIO 外设的通用流程。
