# #ifndef 头文件卫士

> 全称 "If Not Defined"（如果未定义）。每个 `.h` 文件必须包的防重复外壳。

---

## 一、标准写法

```c
#ifndef __BSP_LED_H      /* 如果没定义过这个宏 */
#define __BSP_LED_H      /* 立刻定义它 */

/* 头文件真正的内容：函数声明、宏定义、类型定义 */
void led_init(void);
#define LED0 0

#endif                   /* 结束条件判断 */
```

---

## 二、为什么必须加？

`#include` 的本质是**全选复制粘贴**。同一个 `.h` 被多个文件间接包含会重复复制，导致编译报错。

**不加 #ifndef 时**：

```
main.c ──include──→ bsp_led.h ──复制──→ main.o （第一份）
   │
   └──include──→ bsp_delay.h
                     │
                     └──include──→ bsp_led.h ──复制──→ main.o （第二份！）
```

两份 `led_init` 声明同时进入 `main.o`，链接器报 `multiple definition`。

**加了 #ifndef 后**：

| 第几次遇到 | #ifndef 检查 | 结果 |
|-----------|-------------|------|
| 第一次 | `__BSP_LED_H` 没定义 → 成立 | 进入文件，`#define` 打标记，复制内容 |
| 第二次 | `__BSP_LED_H` 已定义 → 不成立 | 跳过所有内容，直接到 `#endif` |

## 三、酒吧盖章比喻

```
保安 = #ifndef
印章 = #define

顾客第一次进门：
  保安看手背 → 没印章 → 盖个章 → 放进去

同一个顾客又来了：
  保安看手背 → 有印章了 → "你进去过了，走吧"
```

## 四、命名规则

| 文件名 | 宏名 |
|--------|------|
| `bsp_led.h` | `__BSP_LED_H` |
| `imx6ull.h` | `__IMX6ULL_H` |
| `bsp_clk.h` | `__BSP_CLK_H` |

> 文件名大写、点换下划线、前后加双下划线。没有硬性规定但大家统一这么写。

---

## 五、速记

```c
#ifndef __文件名大写_H    ← 如果还没定义
#define __文件名大写_H    ← 现在就定义
                         ← 这里是头文件真正内容
#endif                   ← 结束
```

> 以后写任何 `.h` 文件，这三行是肌肉记忆标配。不和编译器商量，直接写。
