# 裸机开发全流程：从源码到运行

> 六个阶段，哪些是机器自动做、哪些你必须亲自动手。

---

## 全景图

```
你写代码          你敲 make              你敲烧录命令        你插卡上电
   │                │                      │                  │
.c .s .lds    gcc→ld→objcopy        imxdownload→dd      芯片跑起来
 Makefile      .o→.elf→.bin          .bin→load.imx        LED亮
              [全自动]              [半自动]
```

---

## 一、写代码（你）

| 文件 | 写什么 | 作用 |
|------|--------|------|
| `main.c` | C 语言业务逻辑 | LED 亮灭、寄存器操作 |
| `startup.s` | 汇编启动 | 设 SVC 模式、设 SP 栈、清零 bss、跳 main |
| `.lds` | 链接脚本 | 规定代码在内存的绝对地址 |
| `Makefile` | 编译规则 | 告诉 make 先编谁后编谁 |

---

## 二、编译 + 汇编（make，全自动）

敲 `make` 后，交叉编译器按顺序干活：

| 步骤 | 工具 | 转换 | 产物 |
|------|------|------|------|
| 预处理 | cpp | 展开 `#include`、`#define` | 展开后的 .c |
| 编译 | gcc | C → ARM 汇编 | `.s` |
| 汇编 | as | 汇编 → 机器码 | `.o` |

`.o` 里的函数地址还是**相对地址**，不能直接跑。

---

## 三、链接（make，全自动）

| 步骤 | 工具 | 转换 | 产物 |
|------|------|------|------|
| 链接 | ld | 所有 `.o` 拼装 + 分配绝对地址 | `.elf` |

链接器严格按照 `.lds` 脚本：

- 把 `startup.o` 放在 `0x87800000`
- 其余代码接在后面
- 分配 `.rodata` / `.data` / `.bss`
- 打上 `__bss_start` / `__bss_end` 标号

`.elf` 有完整元数据（符号表、调试信息），在 Linux 系统里直接能跑。但裸机芯片不认这些"说明书"。

---

## 四、格式转换（make，全自动）

| 步骤 | 工具 | 转换 | 产物 |
|------|------|------|------|
| 提纯 | objcopy | 剥掉元数据，只留机器码 | `.bin` |
| 反汇编 | objdump | `.elf` → 汇编 + 地址 | `.dis` |

`.bin` 就是喂给芯片的**纯二进制口粮**。`.dis` 是查错用的地址对照表。

---

## 五、烧录（你操作）

这一步不能只靠 `make`。

| 方式 | 命令 | 场景 |
|------|------|------|
| 只生成 load.imx | `./imxdownload led.bin /dev/null` | 无 SD 卡时 |
| 直接烧 SD 卡 | `sudo ./imxdownload led.bin /dev/sdb` | 虚拟机接管了 SD 卡 |
| Mac 物理烧录 | `sudo dd if=load.imx of=/dev/rdisk4 bs=1024 seek=1 conv=sync` | 混合双打模式 |

工具做的事：

```
led.bin → +IVT头部 + DCD(DDR初始化参数) → load.imx → 写到 SD 卡第 1024 字节处
```

> 不是文件拷贝！是绕过文件系统直接写物理扇区。

---

## 六、运行（你插卡上电）

```
上电 → Boot ROM 读 SD 卡 1024 字节处
      → 读 DCD → 初始化 DDR
      → 搬 led.bin 到 0x87800000
      → 跳转 _start（startup.s）
           → 设 SVC 模式
           → 设 SP 栈指针
           → 清零 bss
           → b main（main.c）
                → LED 亮
```

---

## 你的日常三步

```
1. 写代码（VS Code）
2. make（终端敲一下，编译+链接+提纯全自动）
3. 烧录 + 插卡上电
```

> 如果买了 USB 读卡器直连虚拟机，第 3 步也简化成一条命令。

---

## 机器 vs 你

| 阶段 | 谁做 | 你只需 |
|------|------|--------|
| 编译 .c→.o | 机器 (gcc) | 写对 Makefile |
| 汇编 .s→.o | 机器 (as) | 写对 startup.s |
| 链接 .o→.elf | 机器 (ld) | 写对 .lds |
| 提纯 .elf→.bin | 机器 (objcopy) | Makefile 里配好命令 |
| 烧录 | 你 | 敲 imxdownload 或 dd |
| 运行 | 硬件 | 插卡 + 上电 |
