# C 语言运行环境构建

> C 语言不能裸跑。在调 `main()` 之前，汇编必须铺好三样东西：权限、栈、跳转。

---

## 一、设置 SVC 模式（给超级管理员权限）

Cortex-A7 有 8 种运行模式，裸机开发需要 SVC（Supervisor）——相当于 Linux root 权限。

### 为什么选 SVC

| 模式 | 权限 | 场景 |
|------|------|------|
| USR（用户） | 低 | 普通应用程序 |
| SVC（管理） | 最高 | 裸机/OS 内核 |
| IRQ/FIQ | 中断 | 响应外设 |

裸机要随意操控硬件寄存器，非 SVC 不行。虽然上电默认就是 SVC，但保险起见手动确认一遍。

### 怎么设

CPSR 寄存器的低 5 位（bit[4:0]）控制模式：

| M[4:0] | 模式 |
|--------|------|
| `10011` = 0x13 | SVC |
| `10000` = 0x10 | USR |
| `10010` = 0x12 | IRQ |

```asm
mrs r0, cpsr          @ 读出 CPSR（只能用 MRS，不能 MOV）
bic r0, r0, #0x1F     @ 清低 5 位
orr r0, r0, #0x13     @ 设为 SVC 模式
msr cpsr, r0          @ 写回 CPSR（只能用 MSR）
```

> CPSR 是系统寄存器，LDR/STR 不好使，必须用 **MRS**（读）和 **MSR**（写）。

## 二、设置 SP 指针（给 C 语言搭工作台）

**没有栈，C 语言一条指令都跑不了。**

### C 语言为什么必须有栈？

| 存放内容 | 说明 |
|----------|------|
| 局部变量 | `int a = 0;` 不存寄存器，存栈上 |
| 函数参数 | 调用传参 |
| 返回地址 | 函数执行完回哪 |
| 函数调用链 | 嵌套调用时的上下文保存 |

汇编时代临时数据塞 R0~R12 就够了。C 语言变量多、调用深，寄存器不够用，必须靠栈。

### SP 指到哪？

DDR 物理范围 512MB：`0x80000000 ~ 0x9FFFFFFF`。

| 参数 | 值 |
|------|-----|
| 栈起始 | `0x80200000` |
| 栈大小 | 2MB（`0x200000`） |
| 增长方向 | **向下**（把地址从高往低用） |

```
0x80200000 ─── SP 起始（栈顶）
0x801FFFFC ─── 压入第一个变量后 SP 的位置
    ↓        （每次 push SP 减小）
0x80000000 ─── DDR 底部（栈底）
```

> A7 架构栈向下增长：`PUSH` → SP 减小，`POP` → SP 增大。

```asm
ldr sp, =0x80200000
```

---

## 三、跳转到 C 语言

最后一步：把控制权从汇编交给 C。

```asm
b main
```

> `b` 是无条件跳转，`bl main` 也行（会保存返回地址到 LR，但 main 一般不需要返回）。

---

## startup.s 完整流程

```
上电
 └→ 设置 SVC 模式（保险）
     └→ 设 SP = 0x80200000（C 语言的栈）
         └→ 清零 .bss（C 全局变量归零）
             └→ b main（跳 C）
```

## 与 STM32 对比

| | STM32 | i.MX6ULL 裸机 |
|------|-------|---------------|
| 启动文件 | `startup_stm32.s`（厂家提供） | 自己写 |
| SP 指针 | 自动从向量表加载 | 手动 `ldr sp, =...` |
| .bss 清零 | 启动文件自动做 | 手动写循环清零 |
| SVC 模式 | 默认 | 手动确认 |

> STM32 把所有东西都藏在启动文件里了。裸机开发把每个细节拆开来让你看到。
