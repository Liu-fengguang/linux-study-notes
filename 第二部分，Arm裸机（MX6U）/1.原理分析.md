# 汇编LED原理分析

## 一、为什么要学 Cortex-A 汇编

| 原因 | 说明 |
|------|------|
| 初始化 SOC 外设 | 部分外设需在 C 环境就绪前用汇编初始化 |
| 初始化 DDR | i.MX6U 内部 Boot ROM 已做，不需要手动 |
| 设置 C 运行环境 | 设 SP 指针（一般指向 DDR），C 代码才能跑 |

> 核心目标：用汇编铺好路，C 语言才能上场。

## 二、LED 灯硬件原理分析

### STM32 IO 初始化流程

| 步骤 | 操作 |
|------|------|
| ① | 使能 GPIO 时钟 |
| ② | 设置 IO 复用为 GPIO |
| ③ | 配置 GPIO 电气属性 |
| ④ | 输出高/低电平控制 LED |

### i.MX6ULL IO 初始化

| 步骤 | 寄存器 | 操作 |
|------|--------|------|
| ① 使能时钟 | CCGR0~CCGR6 | 全部写 `0xFFFFFFFF`，使能所有外设时钟 |
| ② IO 复用 | `IOMUXC_SW_MUX_CTL_PAD_GPIO1_IO03` | bit[3:0] 设为 `0101` = 5（ALT5 = GPIO 模式） |
| ③ 电气属性 | `IOMUXC_SW_PAD_CTL_PAD_GPIO1_IO03` | 压摆率、速度、驱动能力、上下拉 |
| ④ 输入/输出 | `GPIO1_GDIR` | bit3 置 1 = 输出模式 |
| ④ 输出电平 | `GPIO1_DR` | bit3：1 = 高电平，0 = 低电平 |

> STM32 和 i.MX6U 流程本质一致：时钟 → 复用 → 电气 → 使用。

## 三、汇编简介

汇编由指令构成，裸机驱动最常用的是 **LDR** 和 **STR**。

### 示例：C 赋值对应的汇编

```c
int a, b;
a = b;
```

假设 `a` 地址 `0x20`，`b` 地址 `0x30`：

```asm
LDR R0, =0x30    @ R0 = b 的地址
LDR R1, [R0]     @ R1 = [R0] = b 的值

LDR R0, =0x20    @ R0 = a 的地址
STR R1, [R0]     @ [R0] = R1，即 a = b
```

### 关键指令

| 指令 | 作用 | 示例 |
|------|------|------|
| `LDR Rd, =imm` | 加载立即数（地址）到寄存器 | `LDR R0, =0x0209C000` |
| `LDR Rd, [Rn]` | 从 Rn 指向的内存读值到 Rd | `LDR R1, [R0]` |
| `STR Rd, [Rn]` | 将 Rd 的值写入 Rn 指向的内存 | `STR R1, [R0]` |
| `B label` | 无条件跳转 | `B main` |
| `BL label` | 跳转并将返回地址存 LR | `BL delay` |
| `BX LR` | 函数返回 | `BX LR` |
| `ORR Rd, Rn, #imm` | 按位或 | `ORR R1, R1, #(1<<3)` |
| `BIC Rd, Rn, #imm` | 按位清 | `BIC R1, R1, #(1<<3)` |

### 寄存器操作本质

对硬件的控制就是：**读 → 改 → 写**

```asm
ldr r0, =REG_ADDR     @ 1. 寄存器地址放入 r0
ldr r1, [r0]          @ 2. 读出当前值
orr r1, r1, #(1<<3)   @ 3. 修改指定位（置 1）
str r1, [r0]          @ 4. 写回寄存器
```

> BIC 清位，ORR 置位。两个指令配合完成大部分 IO 操作。
