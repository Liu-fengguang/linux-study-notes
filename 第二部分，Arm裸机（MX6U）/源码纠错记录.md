# 源码纠错记录

## 错误一览

| 序号 | 行 | 错误 | 修正 |
|------|-----|------|------|
| 1 | 多处 | `ldr r0, = 0x...`（等号后有空格） | `ldr r0, =0x...`（去掉空格） |
| 2 | 注释 | `GPIO1_I003`、`GPI01_I003`、`GPI01_GPI003`（拼写混乱） | 统一为 `GPIO1_IO03` |
| 3 | 注释 | `GPI01_GDIR` 应为 `GPIO1_GDIR` | `GPIO1_GDIR` |
| 4 | 注释 | `GPIO_DR` 应为 `GPIO1_DR` | `GPIO1_DR` |
| 5 | 注释 | `GPI01_GPI003` 应为 `GPIO1_IO03` | `GPIO1_IO03` |

## 逐项说明

### 1. `=` 后多余空格

```asm
@ 错误
ldr r0, = 0x020c4068

@ 正确
ldr r0, =0x020c4068
```

汇编器将 `=` 后的空格视为语法错误，必须紧贴等号。

### 2. GPIO 命名拼写

| 错误写法 | 正确写法 |
|----------|----------|
| `GPIO1_I003` | `GPIO1_IO03`（字母 O 不是数字 0） |
| `GPI01_I003` | `GPIO1_IO03`（1 前面是 GPIO 不是 GPI0） |
| `GPI01_GPI003` | `GPIO1_IO03` |
| `GPI01_GDIR` | `GPIO1_GDIR` |
| `GPIO_DR` | `GPIO1_DR` |

> 命名来源于数据手册，统一写对方便后续查找寄存器地址。

### 3. 注释小问题

```asm
@ 原注释（不准确）
ldr r1, = 0xffffffff @要向CCGR0写入的数据

@ r1 的值在所有 CCGR 中都通用，不止 CCGR0
```

## 代码逻辑

代码逻辑**完全正确**，五个步骤没问题：

```
使能时钟(CCGR0~CCGR6) → IO复用(MUX=5) → 电气属性(0x10B0)
→ 设输出(GDIR bit3=1) → 输出低电平(DR bit3=0) → LED亮 → 死循环
```
