# 启动头文件：IVT、Boot Data 与 DCD

> imxdownload 生成的 `load.imx` 不只是 `led.bin`，前面还粘了一份 3KB 的"说明书"给 Boot ROM 看。

---

## 一、Boot ROM 做了什么

芯片上电，DDR 还是瘫痪的。Boot ROM（芯片出厂固化的死代码）先醒来：

| 步骤 | 操作 | 目的 |
|------|------|------|
| ① 打鸡血 | CPU 内核时钟拉到 396MHz | 让 ROM 自己跑得飞快 |
| ② 开缓存 | 使能 L1/L2 Cache + MMU | 加速启动 |
| ③ 找外卖 | 根据 BOOT_CFG 去 SD/EMMC 读取文件 | 找到 `load.imx` |

> Boot ROM 不认识纯 `led.bin`，它需要一份带说明书的文件。

---

## 二、load.imx 的内部结构

```
load.imx
├── IVT           (32 字节)  ← 目录
├── Boot Data     (32 字节)  ← 快递单
├── DCD           (~3KB)     ← 硬件初始化脚本
└── led.bin                   ← 你的纯代码
```

### IVT（Image Vector Table，镜像向量表）

| 字段 | 内容 |
|------|------|
| 入口地址 | 程序第一条指令在哪 |
| DCD 地址 | DCD 数据存放位置 |
| Boot Data 地址 | Boot Data 在哪 |

> 相当于目录。Boot ROM 先看这里，知道去哪找各段数据。

### Boot Data

| 字段 | 内容 |
|------|------|
| 起始地址 | 代码搬到哪（`0x87800000`） |
| 长度 | 搬多少字节 |
| 插件标志 | |

> 相当于快递单。"请把后面的 bin 代码，原封不动搬到 `0x87800000`"。

### DCD（Device Configuration Data）

**核心中的核心。** 在 DDR 能用之前，必须用 DCD 初始化硬件。

| 配置项 | 操作 |
|--------|------|
| CCGR0~CCGR6 | 全部写 `0xFFFFFFFF`，使能所有外设时钟 |
| DDR 控制器 | 配置上百个参数，初始化 DDR |

> NXP 官方把这些参数从 u-boot 提取出来，做成了表格。Boot ROM 按表格逐条执行。

其他 DCD 子命令：

| 命令 | 作用 |
|------|------|
| 解锁 (Unlock) | 解锁寄存器写保护 |
| 写数据 (Write) | 写入配置值 |
| 检查数据 (Check) | 写完后回读验证 |
| NOP | 占位对齐 |

## 三、SD 卡中的物理布局

### 为什么从 1024 字节开始写

| 偏移 | 内容 | 大小 |
|------|------|------|
| 0 ~ 1023 | 分区表（不能碰） | 1KB |
| 1024 ~ 4095 | IVT + Boot Data + DCD 头部 | 3KB |
| 4096 ~ 末尾 | `led.bin` 纯代码 | |

> `dd seek=2`（跳过 2×512=1024 字节），从第 1024 字节开始写 `load.imx`。

### 数学验证

```
1024 (跳过) + 3072 (头部) = 4096 (代码起点)
```

你写的 `led.bin` 物理上躺在 SD 卡的第 **4096 字节** 处。

## 四、整体流程串联

```
上电
  └→ Boot ROM 醒来（设时钟 396MHz + 开 Cache）
       └→ 读 SD 卡第 1024 字节处
            └→ 读 IVT（目录）→ 知道 DCD 在哪
                 └→ 读 DCD → 逐条执行
                      ├── 使能所有外设时钟（CCGR0~6 = 0xFFFFFFFF）
                      └── 初始化 DDR 控制器
                 └→ 读 Boot Data（快递单）→ 知道搬到哪里
                      └→ 把 led.bin 从 SD 卡搬到 0x87800000
                           └→ 跳转到入口地址 → 你的代码开始跑
```

---

## 五、关键数字速记

| 数字 | 含义 |
|------|------|
| `seek=2` | 跳过 2 扇区 = 1024 字节（保留分区表） |
| 3KB | 头部总大小（IVT + Boot Data + DCD） |
| 4096 | 代码在 SD 卡的物理起点 |
| `0x87800000` | 代码在 DDR 中运行的地址 |
| 396MHz | Boot ROM 启动时设的 CPU 频率 |
