# i.MX6ULL 芯片

## 芯片简介

i.MX6ULL 是 NXP 推出的基于 **ARM Cortex-A7** 内核的低功耗嵌入式处理器，主频最高 792MHz，广泛用于工控、物联网、车载等领域。

| 特性 | 参数 |
|------|------|
| 内核 | ARM Cortex-A7，单核 |
| 主频 | 528MHz ~ 792MHz |
| 制程 | 40nm |
| 内存 | 支持 DDR3/DDR3L/LPDDR2，最大 4GB |
| 外设 | UART、I2C、SPI、CAN、USB、Ethernet ×2、LCD、CSI |
| 封装 | BGA，289 球 14x14mm |

### 对比同系列

| 型号 | 内核 | 主频 | 特点 |
|------|------|------|------|
| i.MX6UL | Cortex-A7 | 528MHz | ULL 前身 |
| i.MX6ULL | Cortex-A7 | 792MHz | 功耗更低、主频更高 |
| i.MX6Q | Cortex-A9 ×4 | 1GHz | 高性能四核 |

## Cortex-A7 架构

### 地位

ARM 将处理器分为三个系列：

| 系列 | 代表 | 定位 |
|------|------|------|
| Cortex-A | A7、A9、A53、A72 | 应用处理器（跑 Linux） |
| Cortex-R | R5、R8 | 实时处理器 |
| Cortex-M | M0、M3、M4、M7 | 微控制器（裸机/RTOS） |

Cortex-A7 属于 A 系列中的**低功耗核心**。

### 工作模式

| 模式 | 代号 | 说明 |
|------|------|------|
| 用户模式 | USR | 普通程序运行，权限最低 |
| 系统模式 | SYS | 特权+用户寄存器 |
| 快速中断 | FIQ | 高优先级中断 |
| 外部中断 | IRQ | 通用中断 |
| 管理模式 | SVC | OS 内核模式（复位默认进入） |
| 中止模式 | ABT | 内存访问异常 |
| 未定义模式 | UND | 未定义指令 |
| 监控模式 | MON | 安全扩展 |

### 寄存器

| 寄存器类型 | 数量 | 说明 |
|-----------|------|------|
| 通用寄存器 | R0~R12 共 13 个 | 日常运算 |
| 堆栈指针 R13 | SP | 指栈顶，每种模式有独立 SP |
| 链接寄存器 R14 | LR | 存返回地址 |
| 程序计数器 R15 | PC | 存当前指令地址 |
| 程序状态寄存器 | CPSR | 当前状态标志 (N/Z/C/V 等) |
| 备份程序状态寄存器 | SPSR | 进入异常时备份 CPSR |

### CPSR 关键位

| 位 | 含义 |
|----|------|
| N(31) | 负数标志 |
| Z(30) | 零标志 |
| C(29) | 进位/借位 |
| V(28) | 溢出 |
| I(7) | 1=禁止 IRQ |
| F(6) | 1=禁止 FIQ |
| T(5) | 1=Thumb 指令集 |
| M[4:0] | 当前工作模式 |

## i.MX6U IO 表示形式

芯片引脚在数据手册中用 `OMUX` 方式命名，每个引脚可复用多个功能。

### 命名规则

```
IOMUXC_SNVS_BOOT_MODE0
│      │    │
│      │    └── 信号名
│      └─────── 功能模块 (SNVS)
└────────────── IO 复用控制器
```

### 另一种常见格式

```
CSI_HSYNC
 CSI     — 所属模块（Camera Sensor Interface）
 HSYNC   — 信号名称（行同步）
```

### 常用命名对照

| 命名片段 | 功能模块 | 用途 |
|----------|----------|------|
| `GPIO` | 通用 IO | 输入输出控制 |
| `UART` | 串口 | 调试、通信 |
| `SPI` | SPI 总线 | 外设通信 |
| `I2C` | I2C 总线 | 传感器、EEPROM |
| `SD` | SD 卡接口 | 存储 |
| `ENET` | 以太网 | 网口 |
| `CSI` | 摄像头接口 | 视频输入 |
| `LCD` | 液晶屏接口 | 显示输出 |
| `SNVS` | 安全非易失存储 | 启动模式、加密 |
| `JTAG` | 调试接口 | 程序下载调试 |
| `BOOT_MODE` | 启动模式选择 | 设置启动介质 |

### 读取 IO 配置

每个 IO 功能由 32 位寄存器控制，涉及两类寄存器：

| 寄存器 | 作用 |
|--------|------|
| `IOMUXC_SW_MUX_CTL_PAD_xxx` | 选择复用功能（ALT0 ~ ALT8） |
| `IOMUXC_SW_PAD_CTL_PAD_xxx` | 电气属性（上下拉、驱动能力、速率） |

> 实际开发时查阅参考手册（Reference Manual）第 32 章 IOMUXC 部分，找到对应引脚配置。
