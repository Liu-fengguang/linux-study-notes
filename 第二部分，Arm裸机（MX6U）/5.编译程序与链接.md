# 编译程序与链接

## 一、编译全流程：四步走

源码到烧录文件，经历四次转换：

```
源码(.s/.c) ─①编译→ 零件(.o) ─②链接→ 带包装成品(.elf) ─③拆包装→ 烧录文件(.bin)
                                                         └④反汇编→ 查错文件(.dis)
```

| 步骤 | 工具 | 输入 → 输出 | 做什么 |
|------|------|-------------|--------|
| ① 编译 | `arm-linux-gnueabihf-gcc -c` | `.c` `.s` → `.o` | 翻译成机器码 |
| ② 链接 | `arm-linux-gnueabihf-ld` | 所有 `.o` → `.elf` | 拼接 + 分配地址 |
| ③ 格式转换 | `arm-linux-gnueabihf-objcopy` | `.elf` → `.bin` | 剥掉元数据，只留机器码 |
| ④ 反汇编 | `arm-linux-gnueabihf-objdump -D` | `.elf` → `.dis` | 逆向为汇编，用于查错 |

---

## 二、每一步在干什么

### ① `.c` `.s` → `.o`：造零件

编译器和汇编器把每个源文件单独翻译成机器码。此时 `.o` 文件**不可运行**——

假如 `a.c` 调用了 `b.c` 里的函数，`a.o` 还不知道那个函数在内存的哪个位置。

> `.o` = 造房子用的砖和预制板，还没拼装。

### ② `.o` → `.elf`：装配 + 贴地址标签

链接器做两件事：

- 把所有 `.o` 拼成一个整体
- 给每行代码分配**绝对内存地址**（比如指定代码在 `0x87800000` 处运行）

ELF 是 Linux 标准可执行格式，里面除了机器码还有大量元数据：符号表、调试信息、段信息等。

> 在 Ubuntu 上写程序，直接运行 `.elf` 就行，Linux 内核会解析它。

### ③ `.elf` → `.bin`：扒光，只剩口粮

裸机开发的关键一步。芯片上电时**没有操作系统**来解析 ELF 里的"说明书"——芯片只会顺着地址一行行读取纯机器指令。

`objcopy` 把 ELF 里的符号表、调试信息、段表全部剥掉，只留机器码，生成 `.bin`。

> `.bin` = 喂给芯片的纯粹口粮，最终烧进 SD 卡的就是它。

### ④ `.elf` → `.dis`：查错照妖镜

把编译生成的 ELF 逆向还原成汇编代码，每条指令带着它的绝对地址。

当程序崩溃抛出一个错误地址时，拿着地址去反汇编文件里对——

> 能精确定位到是哪一行代码崩溃，底层 debug 的核心手段。

## 三、链接与链接起始地址

### 链接是什么

链接就是把所有 `.o` 拼在一起，指定代码在内存中的存放位置。

**链接起始地址 = 代码运行时的起始地址。**

### i.MX6ULL 的 RAM 分布

| RAM 类型 | 地址范围 | 大小 |
|----------|----------|------|
| 内部 RAM (OCRAM) | `0x00900000` ~ `0x0091FFFF` | 128KB |
| 外部 DDR（512MB） | `0x80000000` ~ `0x9FFFFFFF` | 512MB |
| 外部 DDR（256MB） | `0x80000000` ~ `0x8FFFFFFF` | 256MB |

本实验链接起始地址：**`0x87800000`**（落在 512MB DDR 范围内）。

### 还没初始化 DDR，为什么能放 DDR？

`bin` 文件不是直接被芯片执行的——它前面需要**一个头部**：

```
SD卡/EMMC 里的 bin 文件
  ├── IVT 头部（含 DDR 初始化参数）
  └── 真正的机器码
         │
    Boot ROM 读取头部
         │
    ① 根据头部参数初始化 DDR
    ② 把机器码拷贝到链接地址处
    ③ 跳转到链接地址开始执行
```

> i.MX 系列 Boot ROM 负责读头部、初始化 DDR、搬运代码。开发者只需把链接地址写到链接脚本里。

### 关键规则

> **bin 的运行地址 = 链接起始地址**（位置无关代码除外）。不一致会导致绝对跳转跑飞。

## 四、实操命令

```bash
# ① 编译：.s → .o
arm-linux-gnueabihf-gcc -c led.s -o led.o

# ② 链接：.o → .elf（指定链接脚本）
arm-linux-gnueabihf-ld -Tled.lds led.o -o led.elf

# ③ 格式转换：.elf → .bin
arm-linux-gnueabihf-objcopy -O binary led.elf led.bin

# ④ 反汇编：.elf → .dis
arm-linux-gnueabihf-objdump -D led.elf > led.dis
```

> 四步手敲太繁琐 → 用 Makefile 一键自动化。
