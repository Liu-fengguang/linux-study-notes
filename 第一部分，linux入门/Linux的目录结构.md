# Linux 目录结构

Linux 遵循 FHS 标准，所有目录从 `/` 开始，形成单根树。

## 一级目录

| 目录 | 作用 | 说明 |
|------|------|------|
| `/` | 根目录 | 系统起点，所有文件在其下 |
| `/bin` | 基本命令 | 所有用户可用（Ubuntu 20.04+ 已软链到 `/usr/bin`） |
| `/sbin` | 管理命令 | 需 root 权限 |
| `/boot` | 启动文件 | 内核（vmlinuz）、initrd、grub |
| `/dev` | 设备文件 | 硬件抽象为文件（sda、tty、null） |
| `/etc` | 配置文件 | passwd、fstab、ssh/、nginx/ 等 |
| `/home` | 普通用户家目录 | 每个用户一个子目录，存个人文件和配置 |
| `/root` | root 家目录 | 独立于 /home，/home 故障时仍可登录 |
| `/lib` | 共享库 | .so 库文件及内核模块（/lib/modules/） |
| `/media` | 自动挂载 | U 盘、光驱自动挂载点 |
| `/mnt` | 手动挂载 | 临时挂载点 |
| `/opt` | 第三方软件 | 闭源/独立软件（IDE、浏览器） |
| `/proc` | 进程信息 | 虚拟文件系统，数据在内存（cpuinfo、meminfo） |
| `/sys` | 内核信息 | 虚拟文件系统，设备和驱动 |
| `/run` | 运行时数据 | 重启后清空 |
| `/srv` | 服务数据 | Web、FTP 等服务数据 |
| `/tmp` | 临时文件 | 任意用户可写，重启可能清空 |
| `/usr` | 用户程序 | 见下表 |
| `/var` | 可变数据 | 见下表 |

## /usr 子目录

| 目录 | 作用 |
|------|------|
| `/usr/bin` | 用户命令 |
| `/usr/sbin` | 管理命令 |
| `/usr/lib` | 库文件 |
| `/usr/local` | 本地编译安装的软件 |
| `/usr/share` | 架构无关数据（文档、图标） |
| `/usr/include` | C/C++ 头文件 |

## /var 子目录

| 目录 | 作用 |
|------|------|
| `/var/log` | 系统和应用日志 |
| `/var/cache` | 应用程序缓存 |
| `/var/spool` | 打印、邮件等待队列 |
| `/var/lib` | 应用状态数据（数据库文件） |

## /proc 关键文件

| 文件 | 内容 |
|------|------|
| `/proc/cpuinfo` | CPU 信息 |
| `/proc/meminfo` | 内存信息 |
| `/proc/version` | 内核版本 |
| `/proc/<PID>/` | 进程详情 |
