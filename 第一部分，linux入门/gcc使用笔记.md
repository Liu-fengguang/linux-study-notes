# gcc 使用笔记

## 编译四阶段

| 阶段 | 命令 | 输入 → 输出 |
|------|------|-------------|
| 预处理 | `gcc -E hello.c -o hello.i` | `.c` → `.i`（展开宏和头文件） |
| 编译 | `gcc -S hello.i -o hello.s` | `.i` → `.s`（生成汇编） |
| 汇编 | `gcc -c hello.s -o hello.o` | `.s` → `.o`（目标文件） |
| 链接 | `gcc hello.o -o hello` | `.o` → 可执行文件 |

> 一步到位：`gcc hello.c -o hello`

## 常用选项

| 选项 | 作用 |
|------|------|
| `-o file` | 指定输出文件名 |
| `-c` | 编译不链接，生成 `.o` |
| `-g` | 加调试信息（配合 gdb） |
| `-O0` / `-O2` / `-O3` | 优化级别（0 无优化 / 3 最高） |
| `-Wall` | 显示常见警告 |
| `-Werror` | 警告当错误处理 |
| `-I/path` | 指定头文件搜索路径 |
| `-L/path` | 指定库文件搜索路径 |
| `-lmath` | 链接 libmath 库（`-l` 后接库名，去掉 `lib` 前缀） |
| `-std=c99` / `-std=c11` | 指定 C 标准 |
| `-DNAME=VALUE` | 定义宏 |

## 多文件编译

| 场景 | 命令 |
|------|------|
| 分别编译 | `gcc -c main.c` `gcc -c utils.c` |
| 链接 | `gcc main.o utils.o -o app` |
| 一步 | `gcc main.c utils.c -o app` |

## 选项速查

| 需求 | 选项 |
|------|------|
| 只看预处理结果 | `-E` |
| 只编译不链接 | `-c` |
| 输出汇编 | `-S` |
| 调试用 | `-g -O0` |
| 发布用 | `-O2` |
| 全量警告 | `-Wall -Wextra` |
| 指定链接库 | `-l库名 -L库路径` |
