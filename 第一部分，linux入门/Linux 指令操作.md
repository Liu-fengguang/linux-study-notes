# Linux 常用指令

## 目录与路径

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `pwd` | 显示当前路径 | |
| `ls` | 列出目录 | `-l` 详细信息，`-a` 含隐藏文件，`-h` 人类可读大小 |
| `cd` | 切换目录 | `..` 上级，`~` 家目录，`-` 上次目录 |

## 文件操作

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `touch` | 创建空文件 | |
| `mkdir` | 创建目录 | `-p` 递归创建 |
| `cp` | 复制 | `-r` 复制目录 |
| `mv` | 移动/重命名 | mv old new |
| `rm` | 删除 | `-r` 删目录，`-f` 强制 |
| `cat` | 查看文件 | `-n` 带行号 |
| `file` | 识别文件类型 | |

## 搜索

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `find` | 按名/大小/时间搜文件 | `-name "*.log"`，`-size +100M` |
| `grep` | 搜文件内容 | `-r` 递归，`-i` 忽略大小写，`-n` 行号 |

## 磁盘

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `df` | 查看分区空间 | `-h` 人类可读 |
| `du` | 查看目录大小 | `-sh` 汇总，`-sh *` 逐个子目录 |
| `sync` | 内存缓冲刷入磁盘 | |

## 系统

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `uname` | 内核版本 | `-a` 全部信息，`-r` 版本号 |
| `ps` | 进程快照 | `aux` 全部进程 |
| `top` | 进程实时监控 | q 退出 |
| `sudo` | 提权执行 | `sudo su` 切 root |
| `man` | 帮助手册 | q 退出 |
| `reboot` | 重启 | |
| `poweroff` | 关机 | |

## 网络

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `ifconfig` | 查看/开关网卡 | `eth0 down` 关闭，`eth0 up` 开启 |

## 终端

| 命令 | 作用 |
|------|------|
| `clear` | 清屏（Ctrl+L 等效） |
